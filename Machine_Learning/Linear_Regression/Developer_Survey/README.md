# 📊 Análise de Dados da Pesquisa com Desenvolvedores

Este projeto tem como objetivo realizar uma **análise exploratória de dados (EDA)** e desenvolver um **modelo preditivo utilizando Regressão Linear** com base em um conjunto de dados de desenvolvedores.  

O trabalho foi desenvolvido em **Python** dentro de um ambiente Jupyter Notebook.

---

## 🚀 Objetivos
- Explorar e entender os dados da pesquisa com desenvolvedores.  
- Identificar padrões e insights relevantes a partir da análise exploratória.  
- Construir um modelo de **Regressão Linear** para prever variáveis de interesse com base em atributos selecionados.  

---

## 🛠️ Tecnologias Utilizadas
- **Python 3**  
- **Bibliotecas**:  
  - `pandas`  
  - `numpy`  
  - `matplotlib`  
  - `seaborn`  
  - `scikit-learn`  

---

## 🔍 Etapas do Projeto
1. **Carregamento e limpeza dos dados**  
   - Tratamento de valores ausentes.  
   - Ajuste de tipos de variáveis.  

2. **Análise Exploratória (EDA)**  
   - Estatísticas descritivas.  
   - Visualizações gráficas para compreender distribuições e relações entre variáveis.  

3. **Modelagem Preditiva**  
   - Criação de um modelo de **Regressão Linear**.  
   - Treinamento, avaliação e análise da performance do modelo.  

4. **Resultados**  
   - Identificação de fatores relevantes.  
   - Métricas de avaliação do modelo.
       - Métricas de Avaliação do Modelo:
            MAE (Teste): 0.6236
            MSE (Teste): 1.0466
            RMSE (Teste): 1.0230
            R² (Teste): 0.3073
