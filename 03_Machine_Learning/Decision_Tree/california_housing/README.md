# Previsão de Preços de Casas - California Housing Dataset

Este repositório apresenta um projeto de machine learning que implementa o algoritmo de Decision Tree Regressor para prever valores de imóveis na Califórnia. O projeto inclui desde a exploração de dados, pré-processamento, modelagem, tuning e análise dos resultados, com código comentado e visualizações.

## Etapas realizadas
- Exploração dos dados e visualizações iniciais
- Pré-processamento e preparação dos conjuntos de treino/teste
- Construção do modelo Decision Tree
- Avaliação das métricas de desempenho (RMSE e R²)
- Tuning de hiperparâmetros com GridSearchCV
- Interpretação visual da árvore e análise de importância das variáveis
- Conclusão e aprendizados

## Como executar
1. Clone o repositório
2. Instale as dependências (pandas, matplotlib, scikit-learn)
3. Rode o notebook `notebook.ipynb` em ambiente Jupyter ou VSCode

## Resultados principais
- Melhor RMSE: 0.639
- Melhor R²: 0.689
- MedInc (renda média) é a principal variável explicativa
